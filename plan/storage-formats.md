Факты сняты с рабочей машины 2026-11-10 (Claude Code и Codex тех версий, что стояли на эту дату). Форматы не документированы публично и могут меняться с обновлениями агентов, поэтому адаптеры должны переживать неизвестные поля и сообщать о неожиданной структуре, а не падать.

Пометки: **[проверено]** — видел на диске; **[предположение]** — вывод, который нужно подтвердить (задачи в [фазе 0](phases/00-foundation.md)).

## Claude Code

### Корни

- Память проекта: `<профиль>/projects/<закодированный путь>/memory/`. **[проверено]**
- В `~/.claude/projects` 54 каталога проектов, у многих каталог `memory/` пустой. Всего по двум профилям около 300 `.md` в каталогах памяти, включая индексы. **[проверено]**

### Кодирование пути проекта

- Путь кодируется заменой `/` и `.` на `-`: `/home/user/github.com/yarkovaleksei/ai-memory` → `-home-user-github-com-yarkovaleksei-ai-memory`. **[проверено]**
- Кодирование необратимо: `-` в имени нельзя отличить от `/` или `.`. Восстанавливать путь нужно иначе — из поля `cwd` в файлах сессий `*.jsonl` в том же каталоге проекта или подбором по существующим каталогам на диске. **[предположение: что `cwd` есть в jsonl]**
- Встречаются каталоги временных проектов (`-tmp-…`, scratchpad-каталоги). Их нужно показывать отдельной группой или скрывать фильтром.

### Файлы памяти

- Один факт — один `.md` с YAML-frontmatter: **[проверено]**

  ```markdown
  ---
  name: pr-base-branches
  description: одна строка для решения о релевантности
  metadata:
    type: feedback            # user | feedback | project | reference
    node_type: memory         # встречается не везде
    originSessionId: <uuid>   # встречается не везде
    modified: 2026-10-06T14:45:14.623Z  # встречается не везде
  ---

  Текст факта. Для feedback/project — строки **Why:** и **How to apply:**.
  Ссылки на другие факты — [[slug]].
  ```

- Распределение типов по выборке: feedback ≈ 95, project ≈ 76, reference ≈ 21, user ≈ 4. **[проверено]**
- Возможны старые файлы с `type` на верхнем уровне frontmatter или вовсе без frontmatter. Парсер должен это принимать. **[предположение]**
- `MEMORY.md` — индекс без frontmatter, по строке на факт: `- [Заголовок](файл.md) — зацепка`. Индекс загружается в контекст каждой сессии, факты читаются по нему. **[проверено]**
- Следствие: любое создание, переименование или удаление факта обязано обновить `MEMORY.md`. Иначе Claude не увидит новый факт или будет ссылаться на несуществующий.

### Соседи, которые нельзя трогать

- `history.jsonl`, `sessions/`, `settings.json`, `plugins/`, `.credentials.json` и прочее в профиле. Читаем только `projects/*/memory/` и, для восстановления пути, `cwd` из `projects/*/*.jsonl`.

### Единственный безопасный канал записи

Записывать в память Codex можно только ad-hoc-заметками:

- **добавить факт** — новая заметка;
- **изменить факт** — новая заметка, которая уточняет или заменяет прежний (правка нашей же заметки тоже допустима);
- **удалить факт** — заметка «забыть: …» с точной формулировкой, что исключить;
- **удалить заметку** — нельзя; можно переписать её содержимое на отмену.

Эффект виден только после очередной консолидации. Когда она запускается, неизвестно (вопрос в [open-questions.md](open-questions.md)).
