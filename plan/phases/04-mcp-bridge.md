# Фаза 4. MCP-мост

**Статус:** не начата

**Цель.** Дать каждому агенту доступ к памяти другого прямо во время работы, без ручного переноса.

## Задачи
- [ ] `packages/mcp`: stdio MCP-сервер поверх `packages/core`.
- [ ] Инструменты только на чтение: `search_memory(query, project?, agent?)`, `get_memory(id)`, `list_projects()`.
- [ ] По умолчанию агент видит память другого агента по текущему проекту; глобальная — по флагу.
- [ ] Опционально и выключено по умолчанию: `propose_memory(...)` — создаёт черновик плана, который применяет человек в GUI. Агент сам ничего не пишет.
- [ ] Инструкция по подключению: `claude mcp add …` и раздел `[mcp_servers]` в `~/.codex/config.toml`.
- [ ] Тесты: протокольные тесты инструментов на фикстурах.

## Готово, когда
- В сессии Codex по проекту из фикстуры агент находит через MCP факт, который есть только в памяти Claude, и наоборот.
- Ни один инструмент MCP не меняет файлы на диске.

## Риски
- Чужая память раздувает контекст. Смягчение: короткие выдачи (заголовок, описание, id), тело — только через `get_memory`.
