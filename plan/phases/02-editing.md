# Фаза 2. Редактирование

**Статус:** не начата

**Цель.** Править, создавать и удалять память обоих агентов так, чтобы любую операцию можно было посмотреть до записи и откатить после.

## Задачи

### Исследование
- [ ] Закрыть Q2 и Q3: когда Codex консолидирует память и откуда читает ad-hoc-заметки ([open-questions.md](../open-questions.md)).

### core: writer
- [ ] `WriteOp` (`create`, `update`, `delete`) и `WritePlan` — список файловых изменений с diff.
- [ ] Claude: создание факта (имя файла из slug, frontmatter, строка в `MEMORY.md`), правка, удаление (файл и строка индекса), исправление расхождений индекса.
- [ ] Codex: новая заметка, правка нашей заметки, заметка «забыть» для удаления факта. Удаление файла заметки невозможно на уровне API.
- [ ] Проверки: `hash` файла, lock-файл Codex, путь внутри разрешённых корней, отказ на симлинк наружу.
- [ ] Атомарная запись через временный файл и `rename`.
- [ ] Репозиторий бэкапов `~/.local/share/ai-memory/backups`: снимок до, коммит после, сообщение с описанием операции.
- [ ] Откат операции по коммиту бэкапа — тоже через план и diff.
- [ ] Тесты на фикстурах: каждая операция, конфликт `hash`, активный lock, попытка выйти за корень, откат.

### server
- [ ] `POST /api/plans` — построить план без записи.
- [ ] `POST /api/plans/:id/apply` — применить подтверждённый план.
- [ ] `GET /api/history`, `POST /api/history/:id/revert`.

### web
- [ ] Редактор Markdown (CodeMirror 6) и форма frontmatter для фактов Claude.
- [ ] Диалог подтверждения с diff по каждому файлу (`@codemirror/merge`).
- [ ] Для записей Codex вместо «Изменить» — «Уточнить заметкой» и «Забыть», с пояснением, что изменение вступит после консолидации.
- [ ] Статус «ожидает консолидации» у заметок, ещё не отражённых в `memory_summary.md`.
- [ ] Экран истории с откатом.
- [ ] Массовые действия в списке: удалить выбранные (через один общий план).

## Готово, когда
- Факт Claude, созданный в интерфейсе, виден в новой сессии Claude Code в этом проекте.
- Заметка, созданная в интерфейсе, после консолидации отражена в `memory_summary.md` Codex.
- Любая операция откатывается из истории, и после отката файлы побайтно совпадают с исходными.
- Тестами доказано, что сгенерированные файлы Codex и файлы заметок никогда не удаляются и не переписываются writer'ом.

## Риски
- Агент пишет в тот же файл одновременно с нами. Смягчение: проверка `hash` перед записью, lock Codex, совет закрывать сессии перед массовыми правками.
