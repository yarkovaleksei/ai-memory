# Фаза 2. Редактирование

**Статус:** в работе

**Цель.** Править, создавать и удалять память обоих агентов так, чтобы любую операцию можно было посмотреть до записи и откатить после.

### Сервисы Wails (`internal/app`)
- [x] `PlansService` строит план без записи — отдельный метод на операцию (`CreateFact`, `UpdateFact`, `UpdateSource`, `DeleteFacts`, `FixIndex`, `CreateNote`, `ForgetNote`) — и держит его в памяти по ID; `Draft(itemID)` отдаёт файл и его хэш для редактора, и план строится от этого хэша, а не от свежего индекса.
- [x] `PlansService.Apply(planID)` — применить подтверждённый план; план одноразовый. `Discard(planID)` — забыть неподтверждённый. `Status()` — включена ли запись (без git — нет) и состояние консолидации Codex.
- [x] `HistoryService.List()`, `HistoryService.Revert(commit)` — история и откат (откат тоже возвращает план; откат создания заметки Codex отклоняется сразу).

### Приёмка
- [ ] Ручная приёмка на реальной памяти — только с согласия владельца в чате: факт Claude из интерфейса виден в новой сессии Claude Code, заметка учтена консолидацией Codex, откаты байт в байт.

## Готово, когда
- Факт Claude, созданный в интерфейсе, виден в новой сессии Claude Code в этом проекте.
- Заметка, созданная в интерфейсе, после консолидации отражена в `memory_summary.md` Codex.
- Любая операция откатывается из истории, и после отката файлы побайтно совпадают с исходными. Исключение — создание заметки Codex: файл заметки удалять нельзя ([ADR-002](../decisions.md#adr-002-в-память-codex-писать-только-ad-hoc-заметками)), отмена — заметкой «забыть» ([ADR-012](../decisions.md#adr-012-бэкапы-через-системный-git-блокировка-codex-через-его-же-lock-файл)).
- Тестами доказано, что сгенерированные файлы Codex и файлы заметок никогда не удаляются и не переписываются writer'ом.

## Риски
- Агент пишет в тот же файл одновременно с нами. Смягчение: проверка `hash` перед записью, lock Codex, совет закрывать сессии перед массовыми правками.
- Агент консолидации Codex может править каталог поколения целиком, включая заметки, а `codex debug clear-memories` удаляет и их. Смягчение: наши заметки сохраняются в репозитории бэкапов ai-memory, и их можно восстановить.
