# Фаза 6. Упаковка

**Статус:** не начата

**Цель.** Устанавливать и запускать ai-memory как обычное приложение на Linux, macOS и Windows ([ADR-009](../decisions.md#adr-009-linux-macos-и-windows-с-самого-начала)).

`wails3 build` уже даёт один бинарь, поэтому фаза сводится к установочным пакетам, ярлыкам и обновлению. Память только локальная: один компьютер — одна установка (Q5 закрыт).

## Задачи
- [ ] Linux: AppImage и/или deb через `wails3 package`, ярлык `.desktop` и иконка.
- [ ] macOS: `.app` в `.dmg`. Решить, подписывать ли и нотаризовать (нужен аккаунт Apple Developer); без этого — инструкция, как открыть неподписанное приложение.
- [ ] Windows: установщик (NSIS через Wails), проверка WebView2. Решить вопрос подписи.
- [ ] Записать выбранные форматы и решение о подписи в ADR.
- [ ] Сборка пакетов в CI на GitHub Actions по тегу версии, артефакты — в релиз GitHub.
- [ ] Бинарь MCP-моста ставится вместе с приложением и находится по известному пути на каждой системе.
- [ ] Версия приложения видна в интерфейсе и в `ai-memory-mcp --version`.

## Готово, когда
- ai-memory ставится одним пакетом и открывается из меню приложений на каждой из трёх систем.
- Обновление выполняется установкой нового пакета и не трогает индекс и бэкапы в [каталоге данных](../architecture.md#каталоги-ai-memory).
