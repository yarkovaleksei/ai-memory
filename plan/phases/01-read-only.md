# Фаза 1. Просмотр (MVP)

**Статус:** не начата

**Цель.** Увидеть память обоих агентов в одном окне: по проектам, с поиском, без единой записи на диск. Это MVP: уже полезно и абсолютно безопасно.

## Задачи

### core
- [ ] Модель `Source`, `Project`, `MemoryItem` ([architecture.md](../architecture.md#модель-данных)).
- [ ] Адаптер Claude: обнаружение профилей, обход `projects/*/memory`, парсинг frontmatter с допуском вариантов, восстановление пути проекта, сверка с `MEMORY.md` (расхождения — отдельный признак у записи).
- [ ] Адаптер Codex: активное поколение (по Q1), разделы `memory_summary.md`, заголовки и тело `rollout_summaries`, ad-hoc-заметки. Привязка к проекту по `cwd`.
- [ ] Нормализация проектов: один `Project` на реальный путь, объединяющий источники обоих агентов; глобальная память — проект `global`.
- [ ] Индекс SQLite + FTS5, полная пересборка при запуске.
- [ ] Наблюдатель файлов: инкрементальное обновление индекса.
- [ ] Тесты адаптеров на фикстурах, включая кривые файлы.

### server
- [ ] Hono на `127.0.0.1`, токен сессии, проверка `Origin`/`Host`.
- [ ] `GET /api/projects`, `GET /api/items?project=&agent=&type=&q=&_sort=&_page=`, `GET /api/items/:id`, `GET /api/sources`.
- [ ] Ответы в форме, удобной для react-admin (`X-Total-Count` или `{ data, total }`).
- [ ] Server-sent events: «индекс обновлён», чтобы интерфейс перечитал список.

### web
- [ ] react-admin с собственным `dataProvider` (только `getList`, `getOne`, `getMany`).
- [ ] Раскладка: слева дерево проектов, в центре список записей с бейджами агента и типа, справа просмотр записи (отрендеренный Markdown и сырой текст).
- [ ] Фильтры: агент, тип, проект, «временные проекты», «расхождения с индексом».
- [ ] Полнотекстовый поиск с подсветкой.
- [ ] Ссылки внутри памяти кликабельны: `[[slug]]` у Claude, `rollout_summaries/…` у Codex.
- [ ] Светлая и тёмная тема.

## Готово, когда
- `npm run dev` открывает интерфейс, где на реальных данных владельца видна память обоих профилей Claude и Codex.
- Один и тот же проект, известный обоим агентам, показан одной строкой с обоими источниками.
- Поиск находит факт по слову из тела меньше чем за секунду на объёме машины владельца.
- Тестом доказано, что ни один код фазы не пишет за пределы `~/.local/share/ai-memory` (например, запуск на фикстурах в read-only-копии).

## Риски
- Большие файлы v1 (`MEMORY.md` 586 КБ, `raw_memories.md` 1 МБ). Смягчение: v1 по умолчанию выключено; если включено — нарезка на разделы и ленивая загрузка тела.
