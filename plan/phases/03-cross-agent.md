# Фаза 3. Между агентами

**Статус:** не начата

**Цель.** Переносить знания между Claude и Codex и наводить порядок: находить дубли и противоречия, объединять их.

## Задачи

### Исследование
- [ ] Закрыть Q6 (считать ли памятью `CLAUDE.md`, `AGENTS.md`, навыки) и Q8 (не создают ли LLM-вызовы новую память) ([open-questions.md](../open-questions.md)).

### Перенос
- [ ] `move`/`copy` из Claude в Codex: факт → ad-hoc-заметка с указанием источника.
- [ ] `move`/`copy` из Codex в Claude: раздел или пункт summary → файл факта с выбором типа и проекта.
- [ ] Связь «скопировано из» хранится в нашем индексе, чтобы показывать пары и не переносить повторно.
- [ ] Перенос между проектами и между профилями Claude.

### Дубли и объединение
- [ ] Кандидаты в дубли без LLM: FTS-совпадения и сходство по n-граммам внутри проекта и между агентами.
- [ ] Экран «Похожие»: группы кандидатов, сравнение рядом.
- [ ] LLM-объединение по кнопке: `claude -p` или `codex exec` (ADR-005) получает группу и возвращает черновик объединённой записи и список противоречий.
- [ ] `merge` как операция writer'а: одна новая запись, удаление остальных (у Codex — заметка «забыть» для каждой), всё одним планом и одним коммитом бэкапа.
- [ ] Отчёт «противоречия»: пары фактов, которые утверждают разное (например, разные базовые ветки для одного репозитория).

## Готово, когда
- Факт переносится в другой агент в два клика с предпросмотром, и пара «источник — копия» видна в интерфейсе.
- На реальных данных владельца экран «Похожие» находит известные дубли между Claude и Codex.
- Объединение работает одной операцией и откатывается одной операцией.

## Риски
- LLM искажает смысл при объединении. Смягчение: результат — только черновик, diff показывает исходники рядом, применяет человек.
