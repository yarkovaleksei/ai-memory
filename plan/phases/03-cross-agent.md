# Фаза 3. Между агентами

**Статус:** в работе

**Цель.** Переносить знания между Claude и Codex и наводить порядок: находить дубли и противоречия, объединять их.

## Задачи

### Исследование
- [x] Q6 (считать ли памятью `CLAUDE.md`, `AGENTS.md`, навыки) закрыт владельцем: да, это [фаза 4](04-instructions-skills.md).
- [x] Закрыть Q8 (не создают ли LLM-вызовы новую память) ([open-questions.md](../open-questions.md)): не создают при `claude -p --no-session-persistence --tools ""` и `codex exec --ephemeral`; Claude оставляет пустой каталог проекта для рабочего каталога, поэтому он постоянный.

### Перенос
- [x] `move`/`copy` из Claude в Codex: факт → ad-hoc-заметка с указанием источника и проекта в тексте (заметки Codex глобальные).
- [x] `move`/`copy` из Codex в Claude: запись Codex → файл факта с выбором типа и проекта; при переносе тем же планом — заметка «забыть».
- [x] Связь «скопировано из» хранится в метаданных операции в репозитории бэкапов, а не в индексе: индекс — пересоздаваемый кэш, а история переживает его и сама убирает связь при откате переноса. Пары видны в просмотре записи, повторный перенос предупреждается.
- [x] Перенос между проектами и между профилями Claude.
- [x] Откат переноса с участием Codex — одной операцией: созданная заметка переписывается на отмену ([ADR-014](../decisions.md#adr-014-отмена-заметки-codex--переписать-её-текст-на-отмену)).

### Настройки
- [x] Экран «Настройки»: профили Claude (добавить каталог через системный диалог, убрать), корень Codex, поколение Codex и показ неактивного. Пишет только `config.toml` ai-memory, после сохранения память перечитывается без перезапуска. Попросил владелец 2026-11-10: каталоги профилей у всех разные, правка `config.toml` руками неудобна.

### Дубли и объединение
- [x] Кандидаты в дубли без LLM: косинусное сходство TF-IDF буквенных триграмм (`internal/similar`) внутри проекта и между агентами. Порог 0,2 подобран на фикстурах; заметка и раздел сводки Codex парой не считаются — консолидация переносит заметки в сводку намеренно.
- [x] Экран «Похожие»: группы кандидатов, сравнение рядом, фильтр «только между агентами» и порог.
- [x] LLM-объединение по кнопке: `claude -p` или `codex exec` (ADR-005, [ADR-015](../decisions.md#adr-015-llm-черновики-один-запрос-из-постоянного-каталога-кандидатов-отбирает-tf-idf)) получает группу и возвращает черновик объединённой записи и список противоречий. Черновик вписывается в форму «Объединить…», противоречия показываются над ней; запрос можно остановить.
- [x] `merge` как операция writer'а: одна новая запись, удаление остальных (у Codex — заметка «забыть» для каждой), всё одним планом и одним коммитом бэкапа. Итог можно записать на место одного из фактов; без LLM черновик итога — тексты записей подряд.
- [x] Отчёт «противоречия»: пары фактов, которые утверждают разное (например, разные базовые ветки для одного репозитория). На экране «Похожие»: модель сравнивает записи внутри тех же групп одним запросом, у найденной пары — сравнение рядом и «Объединить…».

## Готово, когда
- Факт переносится в другой агент в два клика с предпросмотром, и пара «источник — копия» видна в интерфейсе.
- На реальных данных владельца экран «Похожие» находит известные дубли между Claude и Codex.
- Объединение работает одной операцией и откатывается одной операцией.

## Риски
- LLM искажает смысл при объединении. Смягчение: результат — только черновик, diff показывает исходники рядом, применяет человек.
