# Фаза 3. Между агентами

**Статус:** в работе

**Цель.** Переносить знания между Claude и Codex и наводить порядок: объединять дубли и находить противоречия среди выбранных записей.

### Перенос
- [x] `move`/`copy` из Claude в Codex: факт → ad-hoc-заметка с указанием источника и проекта в тексте (заметки Codex глобальные).
- [x] `move`/`copy` из Codex в Claude: запись Codex → файл факта с выбором типа и проекта; при переносе тем же планом — заметка «забыть».
- [x] Связь «скопировано из» хранится в метаданных операции в репозитории бэкапов, а не в индексе: индекс — пересоздаваемый кэш, а история переживает его и сама убирает связь при откате переноса. Пары видны в просмотре записи, повторный перенос предупреждается.
- [x] Перенос между проектами и между профилями Claude.
- [x] Откат переноса с участием Codex — одной операцией: созданная заметка переписывается на отмену ([ADR-014](../decisions.md#adr-014-отмена-заметки-codex--переписать-её-текст-на-отмену)).

### Объединение и противоречия
- [x] ~~Кандидаты в дубли без LLM (TF-IDF триграмм, `internal/similar`) и экран «Похожие»~~ — сделаны и убраны по решению владельца 2026-11-10: совпадение слов не находит одинаковое по смыслу и связывает лишнее ([ADR-018](../decisions.md#adr-018-без-поиска-похожих-по-совпадению-слов-объединение-и-противоречия--для-отмеченных-в-списке)).
- [x] `merge` как операция writer'а: одна новая запись, удаление остальных (у Codex — заметка «забыть» для каждой), всё одним планом и одним коммитом бэкапа. Итог можно записать на место одного из фактов; без LLM черновик итога — тексты записей подряд.
- [x] «Объединить» для отмеченных в списке «Записи» (ADR-018): факты Claude и записи Codex, которые можно убрать заметкой «Забыть».
- [x] LLM-черновик объединения: `claude -p` или `codex exec` (ADR-005, [ADR-015](../decisions.md#adr-015-llm-черновики-один-запрос-из-постоянного-каталога-кандидатов-отбирает-tf-idf)) получает отмеченные записи и возвращает черновик и список расхождений. Черновик вписывается в форму «Объединить», расхождения показываются над ней; запрос можно остановить.
- [x] «Найти противоречия» для отмеченных в списке: модель получает только их ([ADR-017](../decisions.md#adr-017-модели-уходят-только-отмеченные-записи)) и находит пары, которые утверждают разное (например, разные базовые ветки одного репозитория); у пары — «Объединить».

## Готово, когда
- Факт переносится в другой агент в два клика с предпросмотром, и пара «источник — копия» видна в интерфейсе.
- Отмеченные в списке записи объединяются одной операцией (с черновиком от модели) и откатываются одной операцией.

## Риски
- LLM искажает смысл при объединении. Смягчение: результат — только черновик, diff показывает исходники рядом, применяет человек.
