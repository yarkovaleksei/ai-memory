# План ai-memory

Здесь лежит план всего проекта: что строим, в каком порядке и какие решения уже приняты. План — источник правды для любой работы в репозитории: и человек, и агенты сверяются с ним перед задачей и обновляют его по итогам.

## Цель

Одно десктоп-приложение для памяти Claude Code и Codex. В нём можно просматривать память обоих агентов по проектам, искать, редактировать, удалять, переносить факты между агентами и объединять дубли.

Собственного хранилища памяти у системы нет. Она работает поверх родных файлов агентов, и каждый агент продолжает читать свою память как раньше.

## Как работать с планом

1. Перед задачей найди её в фазе. Если задачи в плане нет, сначала допиши её в нужную фазу и только потом делай.
2. Берись за следующую фазу, только когда предыдущая готова. Исключение — исследовательские задачи, которые снимают вопросы из `open-questions.md`.
3. Отмечай выполненные задачи `- [x]` в том же коммите, что и сам код.
4. Если по ходу пришлось принять архитектурное решение, запиши его в `decisions.md`. Если решение меняет уже записанное, не переписывай старую запись, а добавь новую со ссылкой на старую.
5. Если факт о формате памяти оказался неверным, исправь `storage-formats.md` и пометь, как и когда проверено.
6. Закрытый вопрос из `open-questions.md` переноси в раздел «Закрытые» с ответом и ссылкой на место, где ответ учтён.
